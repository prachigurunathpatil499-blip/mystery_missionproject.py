🔎 Mystery Mission – The Detective Challenge

About the Project

Mystery Mission is an interactive detective game developed using Python. Players investigate mysterious cases, explore clues, and try to solve the mystery.

Technologies Used

Python

SQLite3

Object-Oriented Programming

Game Cases

The Missing Diamond Necklace

The Missing Laptop

Features

Interactive gameplay

Multiple detective cases

Clue investigation

Player scoring system

SQLite database integration

How to Run the Project

Install Python 3.

Download or clone this repository.

Open the project folder in VS Code.

Run the following command:

python mystery_mission.py
